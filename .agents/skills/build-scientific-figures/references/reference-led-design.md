# Reference-led design from published figures

Use this reference when the author asks to inspect strong figures from published top-conference or
top-journal papers and improve a new figure by learning from them. This is `inspired` mode, not
coordinate-level reconstruction.

## Search for communication analogues

Search official proceedings, anthology pages, or publisher PDFs. Select three to six figures whose
communication job matches the target: branch-and-merge story, method ownership, embodied task
pipeline, grammar or constrained decoding, control/guardrail layer, or evidence plate. Venue prestige
alone is not a match.

Inspect the figure at its native PDF page and at final paper scale. Record a compact audit with:

- paper, venue, year, figure number, and primary URL;
- the figure's communication job and first three-second reading path;
- what receives the largest visual area;
- how physical imagery, abstract modules, text, and connectors divide responsibility;
- one principle to adopt, one tempting feature to reject, and the reuse/provenance boundary.

Use this template so figure identity and visual conclusions remain auditable:

| Paper / venue / year | Figure and PDF page | Communication job | First reading path | Dominant visual anchor | Adopt | Reject | Source / license / bundling boundary |
| --- | --- | --- | --- | --- | --- | --- | --- |
| [verified primary-source title] | Fig. N, PDF p. N | [one sentence] | [A → B → C] | [physical scene, result, model, or audit] | [abstract principle] | [source-specific structure or decoration] | [URL, license if known, links-only or authorized bundle] |

Verify figure number, caption, and PDF page from the native paper before recording them. Search-result
thumbnails and remembered figure numbers are not provenance.

Useful published analogues from the authority-aware compilation case study include:

| Reference | Useful visual principle | Do not copy |
| --- | --- | --- |
| [VIMA, ICML 2023](https://proceedings.mlr.press/v202/jiang23b.html) | Physical/task imagery anchors inputs and outcomes while the middle stays abstract. | Task examples, model graph, labels, or icon arrangement. |
| [PaLM-E, ICML 2023](https://proceedings.mlr.press/v202/driess23a.html) | Large visual anchors surround explicitly named central components. | Branding, composition, or embodied examples. |
| [SayCan, CoRL 2022](https://proceedings.mlr.press/v205/ichter23a.html) | The decision mechanism is named where language and feasibility meet. | Robot scenes, score layout, or action vocabulary. |
| [Grammar-Constrained Decoding, EMNLP 2023](https://aclanthology.org/2023.emnlp-main.674/) | Grammar semantics use tokens, brackets, and allowed paths instead of physical objects. | Grammar examples, token sequences, or topology. |
| [NeMo Guardrails, EMNLP 2023](https://aclanthology.org/2023.emnlp-demo.40/) | A control layer is explicit rather than represented by an anonymous gate. | Product styling, dialog examples, or branded assets. |

These links are discovery seeds, not a mandatory reference set. Prefer newer or more relevant
primary sources when the paper's communication problem differs.

## Convert references into an original design

Create a reference-to-decision table before drawing. Translate observations into abstract design
decisions such as “one dominant physical witness,” “semantic middle uses symbolic cartoons,” or
“authority enters only at the compiler.” Then rebuild the composition from the target paper's own
semantic graph.

Change the layout, hierarchy, geometry, palette, connector routing, and icon vocabulary. Never copy
another paper's scientific graph, labels, examples, or recognizable arrangement and merely recolor
it. If several references support the same principle, synthesize the principle rather than choosing
one figure as a template.

Default to storing URLs, figure identifiers, and derived notes. Bundle a screenshot only with
explicit maintainer authorization, recorded source/license, and a private/public reuse boundary.
Existing bundled screenshots may be used for local visual analysis but do not authorize reuse in a
new publication.

## Acceptance

The final figure should explain the target paper without the references present. Provenance should
make the inspired mode explicit, and a reviewer should not be able to mistake a borrowed layout for
the source paper's figure. Review both the standalone artwork and the actual manuscript page.
